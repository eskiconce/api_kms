Funcionalidades Principales

🔑 Content Key Management

  • Generación automática de KID + Key
  • Rotación bajo demanda o programada
  • Caché Redis con fallback a MySQL
  • Historial para VOD (keys anteriores válidas)

📜 License Delivery

  • Proxy a proveedor DRM Widevine
  • Endpoints v1, v2 y proxy binario
  • Validación de tokens
  • Respuesta binaria (application/octet-stream)

👥 VIP Users

  • CRUD completo de usuarios
  • Límites de pantallas concurrentes
  • Sincronización bidireccional con CMS
  • Webhook con autenticación API Key

📊 Monitoring

  • Health checks (Redis, MySQL)
  • Estadísticas en tiempo real
  • Logging detallado de actividad
  • Actividad de licencias por usuario
