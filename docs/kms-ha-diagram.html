Failover Sequence

  • 1. Server A fails (process crash, network, etc.)
  • 2. Health check fails 3 times (6 seconds)
  • 3. Keepalived on B detects MASTER timeout
  • 4. B sends VRRP packet with higher priority
  • 5. VIP moves to B (~3-5 seconds total)
  • 6. Traffic now served by B
  • 7. When A recovers, VIP returns to A (preempt)
